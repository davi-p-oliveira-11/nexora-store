

# Nexora — E-commerce Platform

Nexora is a full-stack e-commerce platform with a complete product, checkout, and order management system. It includes an admin panel, real-time customer interactions, and media optimization for product assets.

The system is designed with a production-style architecture, focusing on scalability, clean UI flows, and integration with modern backend services.

---

## 🚀 Live Demo

https://nexora-store.onrender.com/

---

## ✨ Core Features

- Full product catalog with category filtering
- Admin dashboard for product creation, editing, and deletion
- Image upload and optimization via ImageKit
- Shopping cart with persistent state
- Secure checkout flow
- Order tracking and order details view
- Real-time order chat for customer support
- Video call integration for order support sessions
- Role-based access control (admin / customer)
